# Kana Drill

A hiragana chart and trainer that runs in the browser.

- **Chart**: the full hiragana chart (basic, dakuten/handakuten, yōon). Tap a kana for its sound, an example word, and tips for telling lookalikes apart.
- **Multiple choice**: pick the right answer from four, with lookalikes as the wrong options.
- **Recall**: no timer, no options. Type the romaji, or write the kana and self-mark.
- **Timed drill**: type the romaji and press Check against a timer, with ao5/ao12 averages (wrong answers count as DNF).

Tap row labels on the chart to choose which sections you're tested on. Each kana is tracked as new, learning or learned. Progress is saved in your browser.

Everything is in `index.html`, so it works offline when opened directly as a file.
